Threat scenario

A scammer calls an elderly person posing as a grandchild, a bank advisor or the police, sometimes with an AI-cloned voice or a spoofed number, and pushes for an urgent, secret payment. Cut the Line sits on the call path: it analyzes unknown callers live, warns the callee, puts the caller on hold, and verifies identity with a 4-digit code texted to the real relative's phone. A voice clone cannot pass it.

Known limitations

  • One US relay number; a carrier could run the same logic natively.
  • Single user, one call at a time; no database yet.
  • Web app rings only while open (no VoIP push without a native app).
  • Spoofed trusted numbers are not analyzed; the code check is the defense.
  • Voice model needs calibration on real phone audio.
  • Amazon Transcribe reuses audio unless an AWS AI opt-out policy is applied.
